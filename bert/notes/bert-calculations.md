# BERT by hand: every calculation

Every number for one sentence pair, at small sizes, from the token IDs to the pre-training loss and one
fill-mask inference. This is the answer key the site's worked examples follow. Everything here was computed
with [bert_example.py](bert_example.py), which you can rerun; it prints every matrix in full.

## Sizes

| | toy version here | paper (BERT-base) |
|---|---|---|
| tokens n | 11 | up to 512 |
| H (d_model) | 8 | 768 |
| heads A | 2 | 12 |
| d_k = H / A | 4 | 64 |
| d_ff = 4H | 32 | 3072 |
| layers L | 1 shown in full | 12 |
| vocabulary V | 16 pieces | 30,000 |

The weights and all three embedding tables are random numbers rounded to one decimal, because a real model
*learns* them. So the attention patterns and predictions below are arbitrary. The point is to see every
operation and shape. Biases inside the encoder and the MLM output bias are left at 0 and LayerNorm uses
γ = 1, β = 0 (their starting values); dropout is skipped, as it is at inference. Lines marked **[code]** follow
the released implementation rather than the paper.
